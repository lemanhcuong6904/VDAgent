# Plan

Cải thiện giao diện workspace hiện có theo các mẫu UI/UX trong [fe-agenttest](https://github.com/mhiu05/fe-agenttest) và dùng [Impeccable](https://github.com/pbakaus/impeccable) để rà soát chất lượng thiết kế. Triển khai trên Vite + React 18 và dữ liệu thật; ưu tiên giao diện sáng, bắt mắt vừa đủ, dễ đọc trong phiên phân tích dài.

## Scope

- In: Workspace của đúng 5 agent hiện tại (`orchestrator`, `data`, `compare`, `insight`, `report`); sidebar, chat, task/inspector, dataset/chart/report, trạng thái tải và lỗi, responsive, accessibility. Giữ `UserPicker` hiện tại để chọn user demo.
- In: Tham khảo sidebar có danh tính và trạng thái agent, topbar gọn, vùng hội thoại dễ đọc, composer nổi bật, panel tiến trình/lịch sử và mobile drawer của repo tham khảo. Chuyển các ý tưởng này thành component/CSS của dự án, không chép logic mô phỏng.
- In: Áp dụng các bước `shape`, `critique`, `typeset`, `layout`, `adapt`, `audit`, `polish` từ [Impeccable](https://github.com/pbakaus/impeccable#whats-included) như tiêu chí thiết kế và kiểm tra qua ảnh chụp. Dùng nền sáng trung tính, chữ đậm rõ, một màu nhấn chính, màu agent nhất quán và khoảng trắng có chủ đích; tránh nhiều card lồng nhau và chữ mờ trên nền màu. Không cài CLI/hook hay đưa Impeccable vào runtime. [Palette tối/vàng trong DESIGN.md](https://github.com/pbakaus/impeccable/blob/main/DESIGN.md) là thương hiệu riêng của repo đó.
- Out: Login/register, session gate, Next.js, React 19, Tailwind migration, “chart agent” thứ sáu, project selector, dữ liệu fixture, trạng thái tiến trình giả và các nút chưa có hành động/API thật. Chart tiếp tục là artifact trong `Inspector`.
- Nguồn tham khảo đã xem tại commit `6a0fdcdd72852beced6940476e2553644750c525`: [workspace](https://github.com/mhiu05/fe-agenttest/blob/6a0fdcdd72852beced6940476e2553644750c525/components/chat-workspace.tsx), [sidebar](https://github.com/mhiu05/fe-agenttest/blob/6a0fdcdd72852beced6940476e2553644750c525/components/layout/workspace-sidebar.tsx), [conversation](https://github.com/mhiu05/fe-agenttest/blob/6a0fdcdd72852beced6940476e2553644750c525/components/conversation/conversation-stream.tsx), [run panel](https://github.com/mhiu05/fe-agenttest/blob/6a0fdcdd72852beced6940476e2553644750c525/components/run/run-progress-panel.tsx). Repo này dùng mock workspace và sáu agent; chỉ lấy mẫu trình bày và tương tác phù hợp với backend hiện có.

## Action items

- [ ] **Chốt sơ đồ màn hình và ánh xạ dữ liệu.** Dựa trên `frontend/src/App.tsx`, `api/types.ts`, `api/queries.ts` và `events/useEventStream.ts`, phác thảo desktop/tablet/mobile: sidebar agent + task, chat trung tâm, inspector task/artifact. Ghi rõ mỗi nhãn trạng thái lấy từ `AgentDTO`, `TaskDTO`, `InvocationDTO` hoặc SSE; thành phần nào không có nguồn dữ liệu thì bỏ khỏi thiết kế.
- [ ] **Chọn hướng thị giác trước khi code.** Phác thảo 2–3 biến thể của cùng màn hình có sidebar, chat, bảng và inspector; so sánh thứ bậc, độ tương phản và mật độ thông tin theo `shape`/`critique` của Impeccable. Chọn một hướng sáng làm chuẩn cho empty/loading/running/result, ghi token màu, chữ và khoảng cách cùng lý do chọn.
- [ ] **Viết kiểm thử hành vi trước khi đổi UI (TDD).** Bổ sung môi trường test component phù hợp Vitest/React 18 và test cho chọn agent/task, hiển thị đúng năm agent khi API trả năm agent, busy/queue, đổi tab inspector, tải/lỗi/rỗng, đóng mở panel và giữ nội dung khi chuyển viewport. Giữ các test sự kiện hiện có; thêm test hồi quy cho luồng chat và task đang dùng.
- [ ] **Thiết lập nền tảng thị giác trong `frontend/src/styles.css`.** Mở rộng CSS variables cho màu, khoảng cách, chữ, bo góc, viền và focus. Chọn font hiển thị dấu tiếng Việt rõ; nội dung chính khoảng 15–16px, metadata thường từ 12–13px, line-height thoáng. Dùng một thang khoảng cách/độ đậm nhất quán; icon có nhãn hoặc tooltip rõ. Ưu tiên tương phản và cấu trúc thông tin hơn gradient, bóng đổ và hiệu ứng trang trí.
- [ ] **Làm lại khung workspace trong `frontend/src/App.tsx`.** Dùng topbar thể hiện agent đang chọn và kết nối SSE, sidebar điều hướng, vùng chat rộng và inspector có thể đóng/mở. Desktop hiển thị song song khi đủ chỗ; tablet/mobile chuyển sidebar và inspector thành drawer/panel có nút mở, nút đóng và quản lý focus, không che composer.
- [ ] **Nâng cấp điều hướng trong `AgentList.tsx`, `TaskList.tsx`, `UserPicker.tsx`.** Hiển thị vai trò/mô tả ngắn, trạng thái busy và queue, item được chọn, task gần đây và status rõ ràng; thêm tìm agent phía client nếu danh sách cần. Danh sách agent tiếp tục đến từ `/api/agents`, không hardcode “chart” hay làm xuất hiện agent plugin bị lỗi tải.
- [ ] **Cải thiện hội thoại trong `components/chat/*`.** Tạo empty state có hướng dẫn và prompt mẫu phù hợp từng agent; tăng khả năng đọc của message, tool result, pending và compacted history; làm composer rõ phím Enter/Shift+Enter, giữ xử lý IME tiếng Việt và lỗi gửi. Giữ logic phân trang và vị trí scroll hiện tại, thêm chỉ báo tin mới khi người dùng đang đọc lịch sử nếu có nhu cầu.
- [ ] **Trình bày tiến trình thật và artifact trong `components/inspector/*`.** Dùng task/invocation tree hiện có để tạo timeline dễ quét, kèm trạng thái running/completed/failed/cancelled và nút cancel hiện có. Làm dataset, chart, report dễ đọc trên màn hình nhỏ; liên kết artifact từ chat tiếp tục mở đúng ID trong inspector. Không hiển thị retry/approve/progress phần trăm khi backend chưa cung cấp hành động hoặc dữ liệu tương ứng.
- [ ] **Kiểm thử theo từng lát chức năng rồi kiểm tra tích hợp.** Theo vòng đỏ → xanh → chỉnh gọn cho từng phần; chạy `cd frontend && npm test` và `npm run build`. Smoke test với backend thật: chọn user demo, gửi tin cho cả năm agent, agent bận/queue, task hoàn tất/lỗi/hủy, SSE reconnect, mở dataset/chart/report và chuyển agent/task mà không mất trạng thái liên quan.
- [ ] **Rà soát chất lượng trước khi hoàn tất.** Làm vòng `critique` → `audit` → `polish` trên ảnh chụp màn hình 1440px, 768px và 390px. Kiểm tra bàn phím, nhãn screen reader, focus drawer, `prefers-reduced-motion`, hội thoại dài, bảng rộng, mất kết nối và agent vắng mặt. Đạt [WCAG 2.2 AA về tương phản văn bản](https://www.w3.org/TR/WCAG22/#contrast-minimum): tối thiểu 4.5:1 cho chữ thường và 3:1 cho chữ lớn; vẫn dùng được ở zoom 200%. Chỉ nhận khi không tràn ngang ngoài vùng dữ liệu có chủ đích, mọi nút hoạt động và trạng thái chính đọc rõ mà không cần dựa vào màu.
